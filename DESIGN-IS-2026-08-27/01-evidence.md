## E9 — environmentally friendly

- Cold `/cases/` load: **803,744 bytes total; 623 KB of JS actually fetched — served uncompressed** (bare uvicorn, no `content-encoding` even when advertised); 750,593 bytes JS on disk, of which 127 KB is never fetched by any page (112,594 B `nomodule` legacy fallback in every route's HTML; 14,377 B chunk referenced by nothing). TTI ≈ 45–110 ms on loopback (floor, not real-network). [Weight §1-3, 6]
- 32–39 requests cold; 16–21 of them are router prefetch of every sidebar destination (~32 KB — more requests than the page's own data); in-app transition afterwards = 1 request / 1,921 bytes. Fonts self-hosted, 2 woff2 files, zero third-party. [Weight §2, 6]
- **Zero idle cost**: 0 running animations, 0 polling, 0 SSE on a terminal run (source-gated at [Workspace.tsx:393-406](caos/frontend/src/components/Workspace.tsx:393)); 0 notifications on load; dark-native single theme; reduced-motion honored. [Weight §4-5, 7; Accessibility §2.7]
- Attention/cognitive cost (part of this principle's software gloss): cognitive-load checklist failed 6 of 8 (three simultaneous primary buttons; 11-control filter group; run console tripled; no run identity echoed; >4-option decision points on five surfaces) → HIGH. [Assessment A §3]
