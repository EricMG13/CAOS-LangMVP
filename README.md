# CAOS-LangMVP

A lean MVP build of CAOS, a credit-analysis workspace that turns source documents, market data, and the Modular OS checkpoint pipeline into committee-ready credit conclusions for institutional leveraged-finance analysts. This repo seeds only the vendored deploy_v methodology bundle, the Modular OS reference material, core contracts, deploy/frontend scaffolding, and a trimmed skill set from the main CAOS project.
