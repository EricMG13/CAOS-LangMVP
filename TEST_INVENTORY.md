# Test Inventory — LEGACY `caos/tests/`

Classification of every test in the legacy CAOS suite ahead of the LangGraph rebuild.

- **Source:** `/Users/ericguei/Claude/Projects/CAOS/caos/tests/` at commit `84f9705` (2026-08-26)
- **Scope:** 16 test files, 18,174 lines, **347 test functions** (each `def test_*` is one row; parametrized cases count as one function). `conftest.py` only prepends `server/` to `sys.path`; `fixtures/` is data — neither contains tests.
- **Method:** every file read in full by parallel readers; per-file row counts verified against `grep -c 'def test_'` ground truth (347/347).
- **Buckets:** CONTRACTUAL = domain guarantee that must hold in any implementation (porting brief included). MECHANISM = assertion bound to the replaced runtime (lease fencing, heartbeats, thread pools, 3-way merge, SSE, SQL migration files, deploy scripts) — the underlying need may survive, the assertion will not. OBSOLETE = out of MVP scope, principally CP-DR. UNCLEAR = needs a ruling; the note says what.
- **Carve-out rule applied:** a test hosted in a CP-DR file whose assertion protects a system-wide invariant (budget ceilings, approval-gate hash binding, source pinning, NaN safety, secret non-persistence) is classified CONTRACTUAL, with the CP-DR vehicle noted. Pure CP-DR schema/flow tests are OBSOLETE.
