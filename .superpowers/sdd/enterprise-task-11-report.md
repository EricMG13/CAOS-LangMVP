## Design (decided before the first test)

Findings that shaped it:

- The provider port already carries a frozen identity (`ProviderIdentity`:
  provider, model, provider version, adapter version, parameter/policy
  context digest, qualification record fields) and a strict qualification
  record with an expiry (Task 5). The harness reuses that identity as the
  binding a result is bound to; it invents no second identity.
- `run.py::build_provider` is the one place a binding is assembled (dual
  credentials refused, OpenRouter development-only, host control
  production-refused). The live binding in the harness is exactly that
  function over `Settings.from_env()`.
- The existing corpus host control (`CorpusProvider` in
  `test_corpus_pathways.py`) proves orchestration on Carnival but is not
  answer-keyed: it emits fixed prose and fixture model tables. The harness
  needs a double that states the *answer key's* facts with citations to the
  blocks that carry them, so that the scorer can be proven end to end.
- The document-first intake (Task 8) classifies, dispositions and routes a
  pack; it refuses packs that name more than one issuer. On the real
  Carnival bytes it does refuse (see follow-ups), so the harness must be
  able to observe an intake refusal as a scored fact and still admit the
  pack through the source routes.
- `read_evidence` is bounded per module (ten reads), so source-complete
  lineage over 30 documents requires spreading reads across the route, as
  the Task 9 double does.
- Every assigned calculator must end as a verified record or a host-declared
  limitation (`_validate_calculation_refs`); "insufficient inputs" is
  expressed by calling the calculator with the inputs the documents support
  and letting the host return `METHODOLOGY_CALCULATION_INCOMPLETE`, never by
  skipping the call.
- openpyxl stamps `dcterms:modified` and zip member times at save time; a
  digest-pinned synthetic workbook needs both fixed.

Decisions:

- **Manifests are JSON per pack, bytes never in them.** `packs/<id>/manifest.json`
  (`caos.corpus-pack.v1`) plus `answer_key.json` (`caos.answer-key.v1`).
  Three byte sources: `synthetic` (regenerated by `synthetic.py`, digest-
  checked), `fetch` (the Carnival documents `fetch.sh` retains; `sources.txt`
  stays the byte manifest CI caches on, and a test pins C01 == sources.txt),
  `external` (`$CAOS_CORPUS_EXTERNAL_DIR/<pack>/`, digests null until the
  owner pins them → `CORPUS_BYTES_UNACQUIRED`). A pack composes: `documents_from`
  borrows another pack's rows and appends its own (C17–C19 borrow C01; C20 is
  C01 plus the licensed workbook).
- **Answer keys are signed by attestation.** The manifest carries the key
  file's SHA-256 and scoped approvals; `host_control` scope licenses the
  orchestration proof, `analyst` scope alone licenses a live cell. `pin`
  re-pins synthetic digests and host-control attestations and refuses to
  re-sign a key under an analyst approval (`ANSWER_KEY_ANALYST_REAPPROVAL_REQUIRED`).
- **One cell = one fresh process and store** (cold by construction); `matrix`
  spawns `cell` subprocesses; `verdict` folds retained results. Every result
  binds identity (model, provider, adapter, parameter/policy digest), corpus
  digest, build (commit, methodology build id + manifest digest), date,
  expiry (`review_days` 90) and reviewer; `aggregate` discards stale or
  expired results (MOD-023/024), needs three passes per live cell, never
  averages, and a refusal never proves a pathway. Host control reads
  `ORCHESTRATION_PROOF`, never `QUALIFIED`.
- **Twelve scoring dimensions**, each `applicable`/`pass`/`detail`: outcome
  (status + static route), facts (match string in an artifact AND a cited
  block of the expected source carrying it), citations (every ref admitted
  and delivered), unsupported claims (forbidden conclusions; every non-year
  figure in Audit Summary/Analysis traceable to delivered evidence, a
  calculation record or the key — fixture model tables exempt only under
  host control and recorded as `exempt_modules`), conflicts (Gaps &
  Conflicts), document use (intake dispositions and refusal, relevant
  documents cited, non-relevant never `MODEL_INPUT`), model effect, refusal,
  latency, budget (used ≤ limits), injection (C12: control vs injected —
  tools, verified-authority digests, budget limits, identity, host identity
  equal; no marker in any artifact; no undeclared tool), ingest steps.
- **Stages.** Run-stage packs go through intake when the host classifies the
  pack onto the cell's route, else through the create-case and source routes
  (the intake never takes a route); overlay cells declare a `prerequisite`
  Full Credit run on the same case. Ingest-stage packs (C08, C10, C13, C15)
  are step lists over the source, intake and loan-universe routes with typed
  expectations. C12 is a paired run.
- **The answer-keyed provider** (`answer_keyed_provider.py`, identity
  `host_control`, adapter `caos.answer-keyed.host-control.v1`) reads each
  fact's block and one block of every other source across the route, runs
  each assigned calculator with the key's inputs (fixtures by default; a
  per-calculator override for "insufficient inputs"), emits the CP-MODEL
  fixture tables for canonical modules when the cell needs a buildable
  model, and states facts (with the source filename), conflicts and gaps in
  a canonical envelope citing only what was delivered.
- **Protected workflow** `.github/workflows/enterprise-qualification.yml`:
  dispatch-only, environment `enterprise-qualification` (credential + an
  encrypted external-pack archive), pinned actions, corpus fetch as in
  `ci.yml`, `plan` then `matrix --binding live`, evidence uploaded
  `if: always()`; no `continue-on-error`.

## Confidence review

Doubts enumerated after the code settled, each investigated to its cause:

1. **Artifact markdown was read from the wrong place.** The first probe
   scored every fact "missing": the harness read `payload.markdown`, but the
   canonical markdown is the `run_artifacts.markdown` column. Fixed; C03
   then linked F1–F3 and handled K1.
2. **A duplicate filename shares its original's source id**, so the
   "never `MODEL_INPUT`" rule flagged C09's copy. Duplicates are now exempt
   from that rule (the original is the model input); the disposition check
   still requires `duplicate`.
3. **Figures in claim sections that are not figures.** The answer-key
   version (`v1.0.0`) and citation brackets (`[src_…/b00044]`) read as
   untraceable numbers. Citations and host identifiers are stripped before
   the numeric scan, the version moved to QA Validation, and Analysis lines
   cite by filename. 13 figures checked on the Carnival Full Credit cell, 0
   untraceable.
4. **"Insufficient inputs" cannot skip a calculator.** `_validate_calculation_refs`
   requires every assigned calculator to end as a record or a host
   limitation; a withheld call is `AGENT_OUTPUT_INVALID`. The double now
   calls the calculator with the inputs the pack supports and states the
   host's `METHODOLOGY_CALCULATION_INCOMPLETE` as a gap (C11 passes with the
   limitation on the artifact). A per-calculator override falls back to the
   fixtures for every other calculator, which is what broke CP-1 first.
5. **Synthetic workbooks were not byte-stable.** openpyxl stamps
   `dcterms:modified` and zip member times; both are pinned in `_stable_zip`,
   verified by two fresh interpreters producing one digest.
6. **The real pack is refused by the document-first intake**
   (`INTAKE_ISSUER_AMBIGUOUS`) — the harness observes and scores the refusal
   and admits through the source routes; recorded as a product follow-up.
7. **Paired C12 runs shared one recorder.** Deliveries from the control run
   would have counted as evidence for the injected run's numeric traceability.
   The recorder is reset between the two runs; identity and call records stay.
8. **`matrix` printed every cell's JSON on one stdout**, so the summary was
   not parseable. Cells are captured; one line per cell goes to stderr.
9. **A blocked binding crashed instead of blocking.** `build_provider`
   raising `AgentError` (dual credentials, development-only adapter) is now
   `BINDING_REFUSED`; the credential check runs before the corpus checks so
   the cheapest missing input names itself (`CREDENTIALS_MISSING` on a live
   cell without a key, verified by the suite).
10. **`after_run` on a refused fresh start** would have raised on a missing
    plan; guarded.
11. **Facts pin one source.** A live model citing the same figure from
    another admitted document scores `stated_uncited`. Deliberate: the key
    names the authority; an analyst may list alternatives in `match`/`source`
    when approving.
12. **Screen-depth cells** read `FULL_DEPTH_REQUIRED` as their model effect
    (NOT_READY) and still link every fact; verified on C01 Full Credit screen
    (51 calls, 12/12 facts).

Not run: rewrite tournaments (decision D4). Not changed: `docs/quality_ledger_coverage.py`'s
two pre-existing duplicate keys (outside the lint scope).

## Open items and follow-ups

- **Document-first intake refuses the real 30-document Carnival pack**
  (`INTAKE_ISSUER_AMBIGUOUS`). Observed 2026-09-03 through `POST /api/intake`
  with every C01 byte: the three annual-report PDFs' text layer splits the cover
  name as `CARNIV AL CORPORATION & PLC`, the half-year report's cover reads
  `RELEASE OF CARNIVAL CORPORATION & PLC`, and the earnings releases read
  `CARNIVAL CORPORATION & PLC`, so `_resolve_issuer` counts three issuers. Task 8
  closed ETR-B01 on synthetic packs; on real bytes the golden journey needs a
  tolerant issuer normalization (collapse intra-word whitespace, strip leading
  "release of"/press-release framing) before it accepts a real pack whole. The
  harness scores the refusal (C01/C17–C20 answer keys, `intake.refusal_code`)
  and admits Carnival through the create-case and source routes. Not fixed here
  (out of Task 11's scope); a candidate that claims the documents-only journey
  on a real pack must close it first.
- **Loan-universe formulas import as blank.** `parse_loan_workbook` opens
  `data_only=True`; a formula cell has no cached value, reads as None, and an
  optional numeric column imports silently (C08 `marks-formula.xlsx`). Recorded
  as observed behaviour in the C08 key; refusing formula cells is an open product
  decision.
- `docs/quality_ledger_coverage.py` carries two pre-existing duplicate
  dictionary keys (`draft-history-smoke`, `identity-a11y`) that Ruff flags
  under F601 when the file is linted directly; `docs/` is outside the
  repository's lint scope, so the release lint is unaffected. Left as found.
