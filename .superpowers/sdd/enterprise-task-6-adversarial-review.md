Do not land the working tree as one unit, and do not land it green-washed.** The engine work is real and mostly sound: the calculator execution boundary (`caos/server/caos/methodology/execution.py`) verifies bytes through no-follow descriptors, bounds every input dimension, refuses non-finite values, and binds each record to script, calculator, input and output digests; acceptance now re-verifies vault bytes and replays every calculation before it commits the snapshot, run pointer, case pointer and audit row in one transaction; every module is provider-backed with an enforced assembled-authority digest.
